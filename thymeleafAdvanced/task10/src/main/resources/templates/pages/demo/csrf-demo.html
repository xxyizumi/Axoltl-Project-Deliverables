CSRF対策デモ

CSRFトークンの自動挿入とAjaxでの送信方法

🔐 現在のCSRFトークン

Spring SecurityがセッションごとにCSRFトークンを生成します。

トークン名: _csrf
トークン値: token-value
ヘッダー名: X-CSRF-TOKEN

📝 通常のフォーム送信

th:actionを使用すると、CSRFトークンが自動挿入されます。

生成されるHTML（開発者ツールで確認可能）:

<form action="/demo/csrf-submit" method="post">
  <input type="hidden" name="_csrf" value="[自動生成されたトークン]" />
  ...
</form>

🔄 Ajax（JavaScript）での送信

AjaxリクエストではCSRFトークンをヘッダーに設定する必要があります。

1. メタタグでトークン情報を埋め込む（headセクション）:

<meta name="_csrf" th:content="${_csrf.token}"/>
<meta name="_csrf_header" th:content="${_csrf.headerName}"/>

2. JavaScript でヘッダーに設定:

const csrfToken = '[[${_csrf.token}]]';
const csrfHeader = '[[${_csrf.headerName}]]';

fetch('/demo/csrf-ajax', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        [csrfHeader]: csrfToken  // ← ここでトークンを設定
    },
    body: JSON.stringify({ message: 'Hello' })
});

⚠️ CSRFトークンなしの送信（403エラー）

CSRFトークンを含めないリクエストは拒否されます。
